# JanSadhak AI

Automated complaint triage for Indian municipal services.

JanSadhak AI reads citizen complaints written in Hinglish (Hindi-English code-mixed text) and classifies each one by **department** and **urgency**, so that critical issues reach the right team faster.

## Status
Work in progress. Currently building and labeling the dataset.

## Planned Features
- Department and urgency classification
- Duplicate complaint detection
- Manual review queue for low-confidence predictions
- Web demo
